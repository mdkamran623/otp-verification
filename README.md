## ✨ Features

<table>
  <tr>
    <td>🔐 <b>Auto-Submit</b></td>
    <td>Automatically validates OTP when all digits are entered</td>
  </tr>
  <tr>
    <td>📋 <b>Paste Support</b></td>
    <td>Paste 6-digit codes directly from clipboard</td>
  </tr>
  <tr>
    <td>⏱️ <b>Resend Timer</b></td>
    <td>Countdown timer with resend functionality</td>
  </tr>
  <tr>
    <td>✨ <b>Animations</b></td>
    <td>Smooth transitions, floating orbs, and pulse effects</td>
  </tr>
  <tr>
    <td>📱 <b>Fully Responsive</b></td>
    <td>Optimized for all screen sizes</td>
  </tr>
  <tr>
    <td>♿ <b>Accessibility</b></td>
    <td>Keyboard navigation and reduced motion support</td>
